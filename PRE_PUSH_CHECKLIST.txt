## 📋 Pre-Push Commands

```bash
# 1. Check what will be committed
git status

# 2. Review changes
git diff

# 3. Add files (the ones we want)
git add .

# 4. Check again to ensure no unwanted files
git status

# 5. If any markdown files appear, they should be ignored
# If db.sqlite3 appears, reset it:
git reset db.sqlite3

# 6. Commit
git commit -m "Your commit message"

# 7. Push
git push origin your-branch
```

## 🧪 Clone Test

After pushing, test on a fresh directory:

```bash
# Clone
git clone <repo-url>
cd ct654-veggieezee

# Verify
cd veggieezee
python setup_verify.py

# Setup
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt

# Initialize
python manage.py migrate
python manage.py sync_prices

# Run
python manage.py runserver 8080
```

## ✅ Success Criteria

After cloning, users should be able to:
1. Install dependencies without errors
2. Run migrations successfully
3. Sync initial data (takes ~15-20 seconds)
4. Start server and access website
5. See predictions working with XGBoost model
6. View fresh data from Kalimati API

## 🚨 Common Issues & Solutions

**Issue**: `ModuleNotFoundError: No module named 'django'`
**Fix**: `pip install -r requirements.txt`

**Issue**: ChromeDriver not found
**Fix**: Automatic download on first `sync_prices`

**Issue**: No data showing
**Fix**: Run `python manage.py sync_prices`

**Issue**: Bot protection error
**Fix**: Normal - selenium will retry automatically
