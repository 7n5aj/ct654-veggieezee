🧠 XGBoost Machine Learning Model

Our prediction system uses gradient boosting trained on historical Kalimati data: a single regressor shared across {{ training_class_count }} commodity label classes, with {{ feature_count }} engineered features per forecast.

🎯 Model Architecture

The system employs XGBoost (Extreme Gradient Boosting), a powerful ensemble learning method that combines multiple decision trees for robust predictions.

  • Algorithm: XGBoost Regressor
  • Input features: {{ feature_count }} engineered columns per prediction
  • Commodity taxonomy: {{ training_class_count }} label-encoder classes (training)
  • Output: Log-transformed NPR price
  • Training Data: Historical Kalimati market prices
  • Fallback: Rule-based model for robustness
  • Predictions UI lists all {{ training_class_count }} classes: live Kalimati names plus archive-only rows when a crop is not on today's API (lags from CSV/DB).

📊 Feature Engineering

The model analyzes {{ feature_count }} engineered features to capture patterns in vegetable pricing:

  • 30-day historical price lags (lag_1 to lag_30)
  • Calendar features (day, month, year, day of week)
  • Seasonal indicators (season encoding)
  • Festival impact factors (major Nepali festivals)
  • Weekly and monthly cycles
  • Vegetable type encoding ({{ training_class_count }} training class names)

✨ Key Features

  • Hybrid Data Approach: Combines static historical data (Excel) with dynamic live prices (API + Database)
  • Automatic Updates: Middleware checks for new data daily and syncs automatically
  • Robust Predictions: XGBoost primary model with rule-based fallback
  • Smart Mapping: Handles commodity name variations between API and training data
  • Confidence Intervals: Dynamic price ranges based on model uncertainty
  • Real-time Dashboard: Live badges, price trends, and predictability indicators
